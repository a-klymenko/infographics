ЯК ЗАПУСТИТИ

1. Розпакуй ZIP.
2. Відкрий розпаковану папку у Visual Studio Code.
3. Відкрий Terminal -> New Terminal.
4. Переконайся, що в цій папці є package.json.
5. Запусти:

npm.cmd install
npm.cmd run dev

Якщо відкритий звичайний cmd, можна:

npm install
npm run dev

ЩО ЗМІНЕНО В ЦІЙ ВЕРСІЇ

1. Верхнє меню зафіксоване.
   Воно завжди видно на екрані при прокручуванні.

2. Темну тему прибрано повністю.
   Немає перемикача світла/темна тема.
   У коді немає логіки darkTheme.

3. Сторінка рівня зроблена як на прикладі:
   зверху назва рівня;
   кнопка назад до рівнів;
   перемикачі "Теорія" і "Завдання";
   теорія в сірих блоках;
   помаранчева кнопка переходу до завдань.

4. Бібліотека не розділяє матеріали за рівнями.
   Всі матеріали йдуть одним списком.
   Є пошук.

5. Типографіка таблиці 2.8 лежить у src/assets/styles.css.

ДЕ ГОЛОВНЕ

src/App.vue
Фіксоване верхнє меню.

src/assets/styles.css
Увесь дизайн, фіксована навігація, кольори, типографіка.

src/data/levels.js
10 рівнів, теорія і завдання.

src/views/LevelView.vue
Сторінка рівня з вкладками "Теорія" і "Завдання".

src/views/LibraryView.vue
Бібліотека одним списком без поділу рівнів.


ДОДАНО КАЧЕЧОК

Зображення качечок лежать у папці:
src/assets/ducks

Підключення зроблено через файл:
src/data/ducks.js

Качечки додані на сторінки:
- Реєстрація
- Рівні
- Бібліотека
- Персонаж
- Проєкт
- Галерея
- Сертифікат

Аватар персонажа тепер теж використовує картинки качечок, а не emoji.

ВИПРАВЛЕННЯ У ЦІЙ ВЕРСІЇ

1. Виправлено кнопку "Далі" після завершення рівня.
2. У теоретичну частину кожного рівня додано повний текст теорії з Word-файлів.
3. У бібліотеці тепер показана вся теорія з усіх 10 рівнів одним списком.
4. Бібліотека не розділяє матеріали на окремі рівні.


ВИПРАВЛЕННЯ ЗНАЧКІВ І ВІДСТУПІВ

1. Повернено значки досягнень у профілі.
   Тепер видно всі 15 значків:
   відкриті — яскраві;
   заблоковані — сірі.

2. Зменшено бокові відступи сторінки.
   Контент і верхнє меню тепер ближче до лівого та правого краю екрана.

3. Файли, які змінено:
   src/data/achievements.js
   src/stores/appStore.js
   src/views/ProfileView.vue
   src/assets/styles.css


НОВІ ПРАВКИ В ЦІЙ ВЕРСІЇ

1. Прибрано напис "01 — Екран реєстрації".
2. Написи "Інфографіка" і "Реєстрація" на сторінці реєстрації тепер по центру.
3. Підказка "Ім’я буде в сертифікаті" стала меншою.
4. На сторінці "Рівні" змінено качечку.
5. Теорія в рівнях тепер групується великими блоками:
   1.1 — заголовок блоку,
   нижче — весь текст у тому самому блоці.
6. У бібліотеці теорія теж показується такими самими більшими блоками.
7. Бокові відступи від країв сторінки ще зменшені вдвічі.


ДОДАТКОВІ ПРАВКИ

1. Бібліотека тепер поповнюється по факту проходження рівня.
   Теорія з'являється після завершення конкретного рівня.

2. Прибрано блок демонстрації на сторінці рівнів:
   - "Кнопка для демонстрації"
   - "Демо: пройти всі рівні"

3. Додано зображення качечок на сторінки:
   - Вхід
   - Рівні
   - Сторінка рівня
   - Бібліотека
   - Персонаж
   - Проєкт
   - Галерея
   - Сертифікат
   - Реєстрація

4. У галерею додано кілька прикладів готових інфографік.


ПОВЕРНЕНО ДЕМОНСТРАЦІЙНИЙ БЛОК

На сторінку рівнів повернено блок:
- Кнопка для демонстрації
- Натисніть, щоб швидко відкрити сертифікат під час перевірки.
- Демо: пройти всі рівні


ВИПРАВЛЕНО ДЕМО-КНОПКУ

Кнопка "Демо: пройти всі рівні" тепер:
1. Позначає всі 10 рівнів як пройдені.
2. Ставить по 82% за кожен рівень.
3. Створює демонстраційну роботу для галереї.
4. Одразу відкриває сторінку сертифіката.


ОСТАТОЧНА ПРАВКА

1. Повністю прибрано демонстраційний блок зі сторінки рівнів:
   - "Кнопка для демонстрації"
   - "Натисніть, щоб швидко відкрити сертифікат під час перевірки."
   - "Демо: пройти всі рівні"

2. Проєкт тепер починається з 0% прогресу:
   - completedLevels: []
   - scores: {}
   - projects: []

3. Змінено ключ localStorage на infographic-app-state-v2-zero,
   щоб браузер не підтягував старий збережений демо-прогрес.


ПРАВКА СЕРТИФІКАТА І ГАЛЕРЕЇ

1. З сертифіката прибрано кнопку "Надрукувати".
2. Приклади робіт у галереї додано як роботи інших авторів.
3. У вкладці "Мої роботи" залишаються тільки роботи користувача.
4. У вкладці "Публічні роботи" показуються приклади інших авторів.


ПРАВКА ГАЛЕРЕЇ

Галерея тепер показується без вкладок:
1. На першому рядку/першому блоці — власні роботи користувача.
2. Нижче, з другого блоку — публічні роботи інших авторів.


SUPABASE ВЕРСІЯ

Ця версія коду вже підключає Supabase:
- Auth для реєстрації та входу;
- таблицю level_progress для прогресу;
- таблицю achievements для досягнень;
- таблицю projects для галереї;
- profiles для імені, email і аватара.

Перед запуском створи .env на основі .env.example.
